# Plan 05-02: Reporter Honor Roll UI & Integrity Display

## Objective

Add the reporter honor roll section to the leaderboard template. Display top reporters with masked identity (first 8 chars of hash), their integrity-weighted score, verified/approved counts, and a trust tier badge. All text in Vietnamese. Use existing light-mode design tokens from Phase 3.

## Context

- **Template**: `templates/leaderboard.html` — has scammer blacklist; needs new reporter section
- **CSS**: `static/css/leaderboard.css` — uses `--mg-*` tokens; Phase 3 light-mode conventions
- **JS**: `static/js/leaderboard.js` — in-page search, modal; must not break existing
- **Data**: `reporter_rankings` list from 05-01, each item: `{rank, reporter_hash_display, total_reports, approved_reports, verified_reports, integrity_score, is_flagged}`
- **Privacy**: Never display full reporter identity — only `reporter_hash_display` (8-char prefix) + rank number

### Task 2 — Add reporter honor roll section to `leaderboard.html`

Insert a new section after the scammer table, before pagination:

```html
<!-- Reporter Honor Roll -->
<div id="reporter-leaderboard" class="mt-5">
  <h3 class="section-title">🏆 Bảng Vinh Danh Tố Cáo</h3>
  <p class="section-desc text-muted">Những người báo cáo đóng góp tích cực nhất, đã được xác minh.</p>
  
  <table id="reporter-table" class="table table-hover">
    <thead>
      <tr>
        <th>Hạng</th>
        <th>Người tố cáo</th>
        <th>Báo cáo được duyệt</th>
        <th>Đã xác minh</th>
        <th>Điểm uy tín</th>
        <th>Cấp độ</th>
      </tr>
    </thead>
    <tbody>
      {% for reporter in reporter_rankings %}
      <tr>
        <td><span class="reporter-rank">#{{ reporter.rank }}</span></td>
        <td><span class="reporter-id">...{{ reporter.reporter_hash_display }}</span></td>
        <td>{{ reporter.approved_reports }}</td>
        <td>{{ reporter.verified_reports }}</td>
        <td class="reporter-score">{{ "%.1f"|format(reporter.integrity_score) }}</td>
        <td>
          <span class="reporter-integrity-badge badge 
            {% if reporter.integrity_score >= 10 %}bg-success
            {% elif reporter.integrity_score >= 5 %}bg-warning text-dark
            {% else %}bg-secondary{% endif %}">
            {% if reporter.integrity_score >= 10 %}Tin cậy cao
            {% elif reporter.integrity_score >= 5 %}Đang đóng góp
            {% else %}Mới tham gia{% endif %}
          </span>
        </td>
      </tr>
      {% else %}
      <tr><td colspan="6" class="text-center text-muted">Chưa có dữ liệu.</td></tr>
      {% endfor %}
    </tbody>
  </table>
</div>
```
