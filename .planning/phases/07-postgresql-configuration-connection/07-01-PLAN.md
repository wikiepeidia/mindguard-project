def load_local_env(filename):
    """Utility to load keys from .env/filename.json"""
    try:
        path = os.path.join(os.path.dirname(__file__), '.env', filename)
        if os.path.exists(path):
            with open(path, 'r') as f:
                return json.load(f)

        return {}

Replace with:

```python
    # Database: NeonDB PostgreSQL (primary), SQLite fallback (local emergency only)
    # Priority: env var DATABASE_URL → .env/postgresql_neondb.json → local SQLite
    _db_url = os.environ.get('DATABASE_URL') or db_config.get('DATABASE_URL')
    if _db_url:
        SQLALCHEMY_DATABASE_URI = _db_url
    else:
        # Emergency local fallback — NeonDB not configured
        SQLALCHEMY_DATABASE_URI = f"sqlite:///{os.path.join(BASE_DIR, 'database', 'mindguard_v2.db')}"

    SQLALCHEMY_TRACK_MODIFICATIONS = False

    # NeonDB engine options: NullPool (pgbouncer handles pooling), pre-ping for auto-suspend
    if SQLALCHEMY_DATABASE_URI.startswith('postgresql'):
        from sqlalchemy.pool import NullPool
        SQLALCHEMY_ENGINE_OPTIONS = {
            "pool_pre_ping": True,
            "poolclass": NullPool,
        }
    else:
        SQLALCHEMY_ENGINE_OPTIONS = {}
```

Key points:

- `_db_url` uses env var first (Vercel), then JSON fallback (local dev) — per D-01
- SQLite fallback ONLY when DATABASE_URL is completely absent — per D-04b
- `NullPool` used only for PostgreSQL connections — per D-02 (avoids pool-on-pool with pgbouncer)
- `pool_pre_ping=True` validates connections against NeonDB auto-suspend — per D-02a
- `sslmode=require` is already in the connection URI string, no need for `connect_args` — per D-02b
- `IS_VERCEL` SQLite `/tmp` branch is completely removed — per D-04, START-02
- `IS_VERCEL` flag itself is kept (line 22) — Phase 8 needs it for seeding removal
- Engine options are conditional: only applied for PostgreSQL URIs, empty dict for SQLite fallback (NullPool is incompatible with SQLite)

1. **Do NOT modify** anything below `SQLALCHEMY_TRACK_MODIFICATIONS` (AI config, Cloudflare, admin config, anti-spam all stay as-is).

**CRITICAL — Cloudflare Turnstile preservation (user requirement):** The Cloudflare config lines (CLOUDFLARE_SITE_KEY, CLOUDFLARE_SECRET_KEY) MUST remain untouched.
