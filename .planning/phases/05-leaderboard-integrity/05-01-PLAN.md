# Plan 05-01: Reporter Leaderboard Data Layer & Integrity Service

## Objective

Build the backend data layer and integrity filtering service for the reporter leaderboard. Query `ScammerReport` grouped by `reporter_hash` to produce ranked reporter stats, then apply integrity rules (exclude cooldown actors, weight verified vs unverified reports, penalize rapid-fire patterns) so the displayed ranking reflects trusted contribution — not raw volume.

## Context

- **Route**: `routes/main.py` `/leaderboard` — currently shows scammers only, needs reporter_rankings context
- **Models**: `ScammerReport` (reporter_hash, status, verification_status, created_at), `AntiSpamActorState` (actor_key, actor_type, cooldown_until, window_count)
- **Anti-spam service**: `services/anti_spam.py` — existing multi-signal decision service; `AntiSpamActorState` records per-actor state
- **Privacy constraint**: reporter identity must stay masked — use `reporter_hash` only; never expose email
- **Goal**: The leaderboard must show top reporters by *integrity-weighted score*, not raw report count

### Task 2 — Implement `services/leaderboard_integrity.py`

New service module. Functions:

```python
def get_reporter_rankings(limit: int = 20) -> list[dict]:
    """
    Returns top reporters ranked by integrity_score.
    Each entry: {
        rank: int,
        reporter_hash_display: str,  # first 8 chars of hash
        total_reports: int,
        approved_reports: int,
        verified_reports: int,
        integrity_score: float,      # weighted score
        is_flagged: bool,            # True if in cooldown or high window_count
    }
    Excludes reporters where is_flagged == True and integrity_score < threshold.
    """

def _compute_integrity_score(approved: int, verified: int, window_count: int) -> float:
    """
    Score formula:
    base = approved * 1.0 + verified * 0.5   # verified adds bonus weight
    penalty = min(window_count * 0.2, base * 0.5)  # rapid-fire penalty, capped at 50%
    return max(base - penalty, 0.0)
    """

def _get_flagged_hashes() -> set[str]:
    """
    Returns set of reporter_hash values currently in cooldown
    from AntiSpamActorState where actor_type='cookie' and cooldown_until > now.
    """
```
