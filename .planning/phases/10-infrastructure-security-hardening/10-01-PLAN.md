<objective>
Remove startup cold-start risk and hardcoded credentials from the codebase before Beta go-live.

Purpose: Two security/performance issues remain before Phase 10 is complete. First, `db.create_all()` runs on every Vercel cold start, adding 500ms–2s of DB round-trip that pushes NeonDB cold-start dangerously close to Vercel's 10s function kill limit. Second, `ADMIN_PASSWORD` and `REPORT_ENCRYPTION_KEY` are hardcoded string literals in `config.py` — anyone reading the source can gain admin access or decrypt sensitive reports. INFRA-03 is already done by teammate (no frontend credential exposure).

Output:
- `app.py` with the two-line `db.create_all()` block removed
- `config.py` with both credentials reading from `os.environ.get()` with no string fallback
- Vercel environment variables set for `ADMIN_PASSWORD` and `REPORT_ENCRYPTION_KEY`
</objective>
